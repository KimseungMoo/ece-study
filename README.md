# 전기공사 기출

전기공사산업기사 필기·실기 개인 학습용 PWA입니다. GitHub Pages 주소는 [https://kimseungmoo.github.io/ece-study/](https://kimseungmoo.github.io/ece-study/)입니다.

아이패드 미니 Safari에서 공유 → **홈 화면에 추가**하면 단독 앱처럼 열립니다. 세로·가로 모두 씁니다.

## 데이터

`/data/`에 올라가는 파일은 암호화된 개인 학습 자료입니다. 문제 원문·해설·그림은 저장소에 평문으로 두지 않습니다. 재배포용이 아닙니다. 이 저장소를 복제해도 암호 없이는 문항을 볼 수 없습니다.

로컬 개발(`npm run dev`)과 테스트만 가상 샘플을 씁니다. 샘플 암호는 `test1234`이고, 실제 시험 내용이 아닙니다. 샘플은 공개 사이트에 올리지 않습니다.

## 사용

1. 사이트를 열고 암호를 입력합니다. 키 유도에 몇 초 걸릴 수 있습니다.
2. **이 기기에서 기억**을 켜면 잠금 해제 키를 이 브라우저에 남깁니다. 다른 사람과 쓰는 기기면 끄세요.
3. 연도별 기출, 오답 분석, 유형 모의고사, 오답노트, 빈출 주제로 공부합니다.
4. 설정에서 학습 기록을 JSON으로 내보내 두세요. 아이패드 저장 공간이 지워질 수 있습니다.

필기 채점은 과목 40점 미만 과락, 전과목 평균 60점 합격입니다. 실기는 정답을 펼친 뒤 맞음/애매/틀림으로 스스로 표시합니다. `현행 KEC와 다를 수 있음` 표시가 있는 문항은 개정 전 기준으로 읽으세요.

## 개발

```bash
npm install
npm run dev          # 샘플 데이터, http://127.0.0.1:5173/ece-study/
npm test             # 복호·모의고사 선택
npm run e2e          # 샘플 잠금 해제 + 화면 캡처
npm run build        # 공개용(암호화 실데이터)
```

배포는 `main` 푸시 시 GitHub Actions가 Pages로 올립니다.
