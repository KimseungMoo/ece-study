# 전기공사산업기사 학습 PWA

아이패드 미니에서 홈 화면 앱처럼 쓰려고 정적 PWA를 만들었다. 주소는 `/ece-study/`, 배포는 GitHub Pages 워크플로.

문항은 저장소에 암호문으로만 둔다. 앱은 암호를 한 번 받아 PBKDF2로 키를 만들고 `verify.bin`으로 확인한 뒤 `data.bin`과 그림 청크를 푼다. 개발·테스트만 가상 샘플(`test1234`)을 쓴다.

화면은 연도별 기출, 오답 유형 분석, 유형 모의고사, 오답노트, 빈출 주제, 학습 기록 JSON 백업이다. 필기는 과락 40 / 평균 60, 실기는 스스로 맞음·애매·틀림을 고른다. KEC 경고와 KaTeX, 오프라인 캐시를 넣었다.
